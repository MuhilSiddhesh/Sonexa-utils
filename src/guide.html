Welcome to Sonexa! To fully enjoy your personal music library, favorite playlists, and recommendations from YouTube and Spotify directly on the desktop app, you need to log in. This article will guide you on how to use the Sonexa Utils Chrome extension to sync your login information safely and quickly.

Prerequisites

Before you begin, make sure you have:

  • Sonexa Desktop App — Download here
  • Google Chrome browser (or any other Chromium-based browser like Edge, Brave, Vivaldi)
  • Sonexa Utils extension — GitHub Repository: A Chrome extension that extracts cookies from YouTube Music and the sp_dc parameter from Spotify for the Sonexa client

Detailed Steps

1 Install the "Sonexa Utils" extension

Follow the installation guide here: Sonexa Utils README

  1. Download the latest release zip from GitHub Releases
  2. Extract the zip file to a folder
  3. Open Chrome and go to chrome://extensions
  4. Enable "Developer mode" in the top right
  5. Click "Load unpacked" and select the extracted folder
  6. The extension icon should appear in your Chrome toolbar
2 Log in to your accounts in the browser

Sonexa Utils reads the login information from your browser's session, so you need to be logged in to both services — YouTube Music and Spotify.

  • Go to music.youtube.com and sign in with your Google account
  • Go to open.spotify.com and sign in with your Spotify account
Note: Make sure you're successfully logged in and can access your personal content (like your playlists, liked songs, and recommendations) on both websites before proceeding.
3 Get the login data from the extension and paste it into the app

For YouTube Music:

  1. Open the Sonexa desktop app first
  2. Go to Settings → Log in to YouTube
  3. Click the dev button in the top-right corner (if available)
  4. Open the Sonexa Utils extension (click the extension icon in Chrome toolbar)
  5. Click Extract Cookies — do this for both String and Netscape format
  6. Back in the app, paste the extracted cookies in the appropriate fields
  7. Done!
4 Repeat the same steps for Spotify
  1. In the Sonexa desktop app, go to Settings → Log in to Spotify
  2. Open the Sonexa Utils extension
  3. Click Extract Cookie for Spotify (this extracts the sp_dc parameter)
  4. Copy the extracted sp_dc value
  5. Paste it into the Spotify login field in the app
  6. Done!
Important: The cookies and sp_dc parameter contain sensitive authentication data. Never share them with anyone. The Sonexa Utils extension only extracts this data locally in your browser — it never sends your data to any external server.

Conclusion

With just a few simple steps, you've unlocked the full power of the Sonexa desktop app. Using the Sonexa Utils extension keeps this process secure — you never enter your passwords directly into the app.

Enjoy your music! If you run into any issues, don't hesitate to contact our support team or create an issue on the Sonexa Utils GitHub.
